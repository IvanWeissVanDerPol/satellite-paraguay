# IP reminder

## Reminder

This document is a reminder to maintain respect for
intellectual property when generating academic papers
and commercial digital products.

## Key principles

1. **Citing** — Always cite sources properly
2. **Plagiarism** — Never copy text or code without attribution
3. **Copyright** — Respect copyright on datasets, images, code
4. **Academic integrity** — Follow institutional guidelines
5. **Indigenous data** — Follow CARE Principles
