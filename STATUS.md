## Axis definitions

### Data real (0-100)
- 100: all required datasets downloaded, validated, versioned in DVC
- 50: partial coverage / one tile of N needed, real but small
- 0: synthetic or completely missing

### Model trained (0-100)
- 100: weights saved, measured F1/R²/MAE on held-out real test, peer-reviewed quality
- 50: trained but not on full data, or measured but only on synthetic
- 0: model exists as code/architecture only, never trained end-to-end

### Paper text / target (0-100)
- Computed: total_words / journal_target × 100
- Plus penalties: TODO templates still present, abstract headline inflated, etc.

### Ethics (0-100)
- 100: IRB approved, FPIC documented, partnership letters on file
- 50: protocol drafted, in-flight communication, partial approval
- 0: no engagement, used sensitive data without permission
