# Abstract

## Yvytu: Multi-Temporal Satellite CV for Chaco Deforestation

We present Yvytu, a multi-temporal satellite computer vision system for deforestation alert generation in the Paraguayan Chaco. Yvytu combines the Prithvi geospatial foundation model (pre-trained on HLS data) with Paraguay- specific fine-tuning using MapBiomas labels. We evaluate against Hansen GFC ground truth across 7,912 Paraguay tiles and demonstrate F1 > 0.85 on deforestation detection. The system generates alerts via email to INFONA and the public dashboard. We release code + models for Paraguay.
