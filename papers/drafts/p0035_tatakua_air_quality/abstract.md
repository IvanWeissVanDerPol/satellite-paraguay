# Abstract

## Tatakua: Air Quality Forecasting for Asunción

We present Tatakua, a deep-learning-based air quality forecasting system for Asunción, Paraguay. Tatakua uses OpenAQ ground measurements, Sentinel-5P atmospheric data (NO2, SO2, CO, O3, CH4), and meteorological features to forecast PM2.5 with MAE < 5 µg/m³ (R² > 0.80). The system is deployed as a real-time dashboard for the Ministry of Public Health.
