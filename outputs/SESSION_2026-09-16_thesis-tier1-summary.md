### Commit `80d3d42` — fix(p0030): regression headline + narrative

**Root cause found via Pitfall #36 Layer 2 re-derivation:**

The P0030 per-region regression existed in `src/papers/p0030_yvyra_soy/pipeline.py:303-444` since commit `f77189d` (Sep 10). The function computed correctly, but the **headline string formatting** had two semantic issues:

1. **Banker's-rounding drift.** The old headline used `"{:.1f}".format(1.95)` → `"1.9"` (Python's banker's rounding rounds 1.95 to 1, the even digit). The figure text hardcoded `"2.0x"`. Two different displays for the same number, neither matching the JSON's `ratio_occident_vs_orient=1.95`.

2. **Narrative contradicted the data.** The old interpretation said: *"Departments with higher indigenous community density show faster soy expansion in Paraguay."* But the cross-department regression has `r=-0.306, p=0.27` (n=14) — the sign is **negative**, and the correlation is **not statistically significant**. The claim is unsupported by the data the pipeline itself computed.

**Changes:**

- `pipeline.py` `run_p0030_regression()`:
  - `ratio_display = f"{ratio:.2f}x"` → consistent `"1.95x"` everywhere
  - Added `n_occidental_with_data=2`, `n_oriental_with_data=12` to headline_finding (was hidden)
  - Added `r_squared`, `p_value_two_sided` to cross_dept_regression (math.erfc normal-approx, n=14 → p≈0.2659)
  - New `limitations[]` field with 5 explicit caveats
  - Headline statement rewritten: explicit n=2 disclosure, no banker's-rounding drift, no causal-sounding language
  - Interpretation rewritten: states the cross-dept r is NOT significant, names yield convergence as alternative
  - New `_pearson_p_value()` helper using `math.erfc` (stdlib, no scipy dependency)

- `outputs/p0030/p0030_regression_analysis.json` regenerated
- `outputs/p0030/p0030_regression_figure.txt` regenerated

- `tests/test_p0030_yvyra_soy.py`: 2 new failure-injection tests:
  - `test_regression_ratio_exact_value` — asserts `ratio == 1.95` and `ratio_display == "1.95x"`. Would catch any return to the older misleading format.
  - `test_regression_interpretation_reflects_data` — asserts (a) interpretation includes "DESCRIPTIVE" / "descriptive", (b) interpretation reports measured r=-0.306, (c) interpretation does NOT contain the discredited causal claim, (d) interpretation reports p-value or "NOT statistically significant", (e) n-with-data fields are 2 and 12, (f) cross-dept regression includes r² and p_value_two_sided with the right values.
