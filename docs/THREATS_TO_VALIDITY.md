# Threat to Validity — Common to All 6 Papers

This document captures threats to validity that apply across the entire
satellite-paraguay mega-thesis. Each paper references this document
in its threat-to-validity section.

## 1. Construct Validity

### 1.1 Synthetic Data
All pilot experiments use **synthetic satellite data** generated by a
simple parametric model (random NDVI values with circular deforestation
events). The synthetic data does not capture:
- Real cloud cover and atmospheric effects
- Sensor noise (Sentinel-2 has 0.01-0.05 reflectance noise)
- Mixed pixels (10 m pixels often contain multiple land covers)
- Phenological variation (real forests have seasonal NDVI patterns)
- Topographic shadows and bidirectional reflectance effects

**Impact:** Synthetic-data metrics may not reflect real-data performance.
In particular, F1 = 0.18 on synthetic data is **not** predictive of F1
on real data.

### 1.2 Ground Truth Limitations
MapBiomas Paraguay labels are **annual summaries** rather than monthly
events. Monthly deforestation events cannot be reliably inferred from
annual labels. Hansen GFC provides annual loss events but is known to
underestimate small clearings (< 1 ha).

**Impact:** Our training labels have inherent noise that affects model
performance estimates.

### 1.3 Class Imbalance
Deforestation is rare (< 2% of pixels per year in most regions).
Models trained on imbalanced data default to predicting the majority
class (no change) and achieve high accuracy but low F1.

**Impact:** F1 metrics are necessary but not sufficient to evaluate
performance. Precision-recall curves are recommended.

## 2. Internal Validity

### 2.1 Limited Training Duration
The pilot experiment uses **5 epochs** because of CPU constraints.
Production-quality training requires 30+ epochs on a GPU. The pilot
results should not be interpreted as model performance limits.

### 2.2 Hyperparameter Selection
Hyperparameters (learning rate, batch size, dropout, etc.) were set
heuristically. **No hyperparameter search was performed.** The
"best" configuration from the ablation study is therefore a local
optimum at best.

### 2.3 Single Random Seed
Most experiments use a single random seed (42). Results have
**unknown variance** across seeds. The ablation study shows variance
across configurations but not within configurations.

### 2.4 Hardware Constraints
All pilot experiments were run on CPU (Intel x86_64, 32 GB RAM).
GPU experiments require Vast.ai rental ($1/hr for A100).

## 3. External Validity

### 3.1 Geographic Specificity
The satellite-paraguay package is **Paraguay-specific**. The 7,912-tile
grid, 18-departamento administrative structure, and indigenous
territory boundaries are unique to Paraguay. Generalization to other
countries requires non-trivial adaptation.

### 3.2 Temporal Specificity
The pilot experiments use 2024 data (synthetic). Real-world applicability
depends on whether the patterns learned generalize across years. The
Chaco deforestation dynamics have changed substantially since 2000
(when Hansen baseline is established).

### 3.3 Atmospheric Conditions
Sentinel-2 imagery is affected by:
- **Cloud cover:** November-March has 40-60% cloud cover in Paraguay
- **Aerosols:** Biomass burning (Aug-Oct) reduces NDVI accuracy
- **Seasonal flooding:** Pantanal region experiences annual flooding

**Impact:** Operational deployment requires cloud-masked composites and
seasonal normalization.

## 4. Conclusion Validity

### 4.1 Multiple Comparisons
The ablation study tests multiple configurations. Without Bonferroni
correction, some "improvements" may be due to chance. **All reported
differences should be treated as exploratory.**

### 4.2 Confidence Intervals
Bootstrap CIs are reported (10,000 resamples). However, the bootstrap
assumes i.i.d. samples, which is violated in spatial data (nearby
pixels are correlated). **Reported CIs are likely too narrow.**

### 4.3 Reported Metrics
F1, precision, and recall are reported. **Per-tile metrics would be
more informative** (variance across 7,912 tiles) but were not computed
in the pilot experiment.

## 5. Ethical Validity (P0012 Yvy)

### 5.1 CARE Principles Compliance
The pilot experiment uses publicly available INDI data with no PII.
Full implementation of CARE Principles requires community engagement,
which is not yet complete.

### 5.2 Detection Bias
Conflict detection depends on Catastro completeness. Regions with
incomplete Catastro will appear as "no conflicts" — this is a data
limitation, not a model performance characteristic.

### 5.3 LLaVA Outputs
LLaVA-1.6 is not yet executed end-to-end. When executed, its outputs
must be reviewed for hallucination before being shown to communities.

## 6. Threats Not Yet Investigated

The following threats are **not yet investigated** and should be
addressed in real-data experiments:

- Adversarial robustness (e.g., designed-to-fool inputs)
- Domain shift (e.g., model trained in 2024 applied to 2025)
- Label noise from MapBiomas annotators
- Cross-departamento variation in model performance
- Long-tail distribution of deforestation sizes
