# Citation Guidelines

How to cite the SatelliteCV-Paraguay megaproyect and its components.

## The megaproyect itself

```bibtex
@software{satelliteparaguay2026,
  title={SatelliteCV-Paraguay: Multi-Temporal Earth Observation of Paraguay},
  author={Weiss Van der Pol, Iv{\\'a}n},
  year={2026},
  version={0.1.0},
  url={https://github.com/IvanWeissVanDerPol/satellite-paraguay},
  doi={10.5281/zenodo.XXXXXXX}  % to be filled
}
```

## How to cite in README

Add to your project README:

```markdown
## Citation

If you use this work, please cite:

```bibtex
@software{satelliteparaguay2026,
  title={SatelliteCV-Paraguay: Multi-Temporal Earth Observation of Paraguay},
  author={Weiss Van der Pol, Iv{\\'a}n},
  year={2026},
  url={https://github.com/IvanWeissVanDerPol/satellite-paraguay}
}
```
```

## BibTeX management

- All references are in `papers/references.bib`
- All chapters use `\bibliography{references}`
- Build with `make thesis-pdf`
- Use Zotero or Mendeley for citation management
