# Glossary — English / Spanish / Guaraní

This glossary covers key terms used across the SatelliteCV-Paraguay mega-project.

## Project terms (Guaraní)

| English | Español | Guaraní | Meaning |
|---------|---------|---------|---------|
| Wind | Viento | **Yvytu** | P0011 — Chaco deforestation (wind brings fires) |
| Earth / Land | Tierra | **Yvy** | P0012 — Indigenous territory mapping |
| Tree | Árbol | **Yvyra** | P0100 — Carbon credits (forests) |
| Paraguay grass | Pasto paraguayo | **Yrupe** | P0025 — Soybean yield |
| Mosquito | Mosquito | **Kai** | P0026 — Wildlife poaching (in Paraguay context = thief/poacher) |
| Hot / Warm | Caliente | **Tatakua** | P0035 — Air quality / temperature |

| Carbon credit | Crédito de carbono | Oñemobyta karbono | Tradeable certificate for CO2 reduction |
| Yield | Rendimiento | Jepokuaa | Agricultural production per hectare |
| Poaching | Caza furtiva | Oñembohape | Illegal hunting |
| Indigenous territory | Territorio indígena | Yvy avañe'ẽ | Land of indigenous peoples |
| Air quality | Calidad del aire | Yvytu porã | Measure of air pollution |
