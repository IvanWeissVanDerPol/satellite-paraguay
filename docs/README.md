# docs/ — SatelliteCV-Paraguay

This directory contains documentation for the SatelliteCV-Paraguay mega-project.

## Contents

| File | Purpose |
|------|---------|
| `DATA_CATALOG.md` | Generated data catalog (local + remote sources) |
| `REPORT.md` | Generated final report (auto-generated by `make report`) |
| `CONTRIBUTING.md` | How to contribute (TBD) |
| `ARCHITECTURE.md` | System architecture overview (TBD) |

## Where things live

- **Source code:** `src/`
- **Configs:** `configs/`
- **Tests:** `tests/`
- **Notebooks:** `notebooks/`
- **Scripts:** `scripts/`
- **Dashboard:** `dashboard/`
- **Models:** `models/` (gitignored)
- **Outputs:** `outputs/` (gitignored)
- **Papers:** `papers/` (gitignored)

## How to use these docs

1. **New to the project?** Start with `DATA_CATALOG.md`
2. **Setting up?** Run `make install` and `make bootstrap`
3. **Running papers?** Check `configs/pXXXX_*.yaml`
4. **Troubleshooting?** Check `logs/autonomous/`

## Generating docs

```bash
make data-catalog  # Generate DATA_CATALOG.md
make report        # Generate REPORT.md
```
