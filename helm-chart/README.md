# Helm chart for deployment

## Helm chart for SatelliteCV-Paraguay

This directory contains a Helm chart for deploying SatelliteCV-Paraguay
to a Kubernetes cluster.

## Files

- `Chart.yaml` — Chart metadata
- `values.yaml` — Default values
- `templates/` — K8s manifests
- `README.md` — This file

## Usage

```bash
helm install satellite-paraguay ./helm-chart
```
